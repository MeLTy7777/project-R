## 動画から確認したい内容(現在の実装が推測ではなくコード根拠で動いている箇所)

| 知りたいこと | 今の実装の根拠 | 動画で食い違いがあったとき |
|---|---|---|
| 背の高い(三頭身)キャラのコマの大きさの指定 | コード: `$` 付きは 幅=画像幅÷`_fN`、高さ=画像高さ÷4(8方向は÷8)。1コマ96×96で実機表示を確認 | 画像の規格(`tools/gen_dev3h_character.cjs`)とプロファイルの `visualHeightPx` を合わせる |
| 背の高いキャラの足元(原点)の扱い | MZ標準(セル下端中央)。足元をコマ最下行に置いて浮かないことを実機で確認 | 画像の余白で調整 |
| アクション(剣/銃)用シートを方向ごとに分ける方法 | 公式の `setImage` + `playFrames` で、方向は4行(下・左・右・上)のシート内に持つ | `actions` の sprite/frames/speed を変更 |
| 8方向の体の作り方 | 未対応(4方向のみ。`directions: 8` の宣言とファイル名 `_8dir` の仕組みだけ) | 8方向素材が用意できたら対応 |
| Idle/Walk/Run の自動切替がプレイヤーで働く条件 | 実機で**働かない**ことを確認し、`ProjectR_CharacterPresentation` が公式の関数を橋渡し(導入順の問題。`docs/ProjectR_CharacterAnimation.md` 第6節) | 動画に推奨のプラグイン順があれば、橋渡しを外してその順にする |

## 現行ドキュメントでは足りない理由

- 公式のテキストマニュアルは「命名規則と再生コマンド」中心で、**大きさ・足元・方向ごとのシート構成**は載っていない。
- 導入済みコードは動作の事実(式)は分かるが、**推奨される作り方・制限**(例: 巨大なシートのメモリ、`PermanentImageCache` のプリロード対象)は分からない。
- そのため、動画があれば上の表を照合するだけで済み、**今回の実装を作り直す必要はない**見込みです。
