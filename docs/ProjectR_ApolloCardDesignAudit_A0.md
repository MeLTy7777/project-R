## 0. 結論(先に)

1. **Apollo 8枚の設計はワークブックにそろっています**(全8枚「確定」、最大コピー数の合計 = 30、入手方法はすべて初期デッキ)。原文の転記 `ProjectR_Cards_15_ExactTranscription.md` は、ワークブックと**554セル全件一致**(不一致0)でした。

3. **実セーブ(保護された5件)に Apollo のカード所持・デッキ・指輪はありません**(Apollo の指輪は未所持、デッキ0枚、所持0)。既存セーブへの影響は、旧Apolloのランタイム定義を触らない限り発生しません(§5)。
4. **設計の曖昧点が多く、特に次の5つは実装前に決定が必要**です: ①黄金の矢の入力方式(Ground なのか方向なのか・長押しの発動タイミング) ②竪琴のリズム入力(攻撃ボタンとの競合・音符の数) ③被ダメージ増減の合成規則(×か+か・「弱点属性」の意味) ④エロスの矢の本数と発射時間・味方の範囲 ⑤新ランタイムIDの命名と旧カードの扱い。詳細は §10。
5. **共有機能の不足**があります(長押し入力、プレイヤーの被ダメージフック、対象別の弱点修飾、敵の遠距離攻撃、敵の攻撃予測など)。実装の最初の Phase は「共有基盤+黄金の矢のLv1〜2」が妥当ですが、**§10 の決定が出るまで着手できません**(§11)。

### 8 黄金の矢(Ground / ∞ / Cooldown 3 / 最大5)
- Lv1: 指定の方向に高速の光の矢を3本同時発射する。間隔は15°。
- Lv2: 5本に増加する。まっすぐ飛ぶ1本が太くなり、スリップダメージダメージ5秒間に計100ダメージ。
- Lv3: 11本に増加する。矢の間隔が10に変更。カード選択ボタンを0.5秒長押しすると一本の矢になり、太さが3マスになる。(ビーム)各矢のダメージが収束する。敵にヒットした場合ヒットストップが発生し、連続ヒットする。
- ダメージ式: 矢1本につき50ダメージ / 攻撃回数: Lv3時のみ連続ヒットする。マス目の大きさによるが、1マスあたり、3ヒットする。
- 成功条件: 射程内の敵にヒットした場合 / 失敗条件: 攻撃が外れる / 対象なし時: 対象外
- 演出: 神=キャラクターの前に召喚・弓を引いて発射・金色の粒子で消える / 主人公=手を前に突きだす / VFX=矢が黄金に輝き電撃を放つ・その後アポロンから光の粒子が漂う / 色=黄金 / 音=竪琴の1音、連続ヒットするたびに竪琴が鳴る / 説明=黄金の矢を放つ

## 7. 属性・状態・ダメージ計算との関係

- 現行の属性システム(Phase 属性・カードバランス、`dd0a6e7`)は MZ 標準の9属性で、固定ダメージにも「基礎値×属性→クリティカル→加算」を1回だけ適用します。**ワークブックの Apollo 行には属性ID の指定がありません**(矢は属性なし=無属性で実装できますが、「Apolloの矢は光属性か」などの意図は未記入 → 決定事項)。
- ワークブックが言及する「弱点属性」: 病(竪琴/疫病の矢)=「弱点属性被ダメージ3%増加」、月桂冠=「弱点属性増加被ダメージ-90%」。現行の弱点修飾 `ProjectRElements.addWeaknessModifier` は**全ダメージに掛かる対象を区別しない修飾**で、「敵が受ける弱点ダメージ」と「味方(主人公)が受ける弱点ダメージ」を別々に扱えません → **対象別(敵側/味方側)の修飾が必要**(§8)。
- 固定ダメージ(1本50・100など)の経路(`projectRFixed`)は、意図的に**物理/魔法ダメージ率(pdr/mdr)を掛けません**。病「被ダメージ+5%」・ギガース「弱点状態 ×2」「傷 +10%」・月桂冠「被ダメージ-30%」を固定ダメージのカードにも効かせるには、**被ダメージ倍率の共通窓口**が必要です。
- 状態(病・弱点状態・傷・精神安定の後継など)は MZ の State で表現できます(例: 病=攻撃力×0.9 の特徴)。ただし「被ダメージ+5%」は pdr/mdr の特徴で表せるのは Skill/武器経路だけ(固定ダメージは対象外)。

## 10. ユーザーに決めてほしいこと(曖昧点・矛盾)

### 共通・基盤
- **A1 命名と旧カード**: ~~新ランタイムID案~~ → **Phase A2 で確定済み**(§4.4)。旧3枚は共存のまま維持(自動変換なし)。置換・統合を将来行うかは未決(実セーブに旧Apolloが無いため可能)。

- **A3 Apolloの指輪の入手方法・初期セットの付与**: Hermes と同じ補充(top-up)で、目標=5/5/2/3/3/5/3/4 でよいか。入手の物語イベント(D4)と報酬ID `apollo.ring.starter`。
- **A4 属性**: Apolloの矢は無属性でよいか。属性を持たせるなら何属性か(ワークブックに記載なし)。
- **A5 被ダメージの合成規則**: 病(+5%)・弱点状態(×2)・傷(+10%)・月桂冠(−30%)・ヒュアキントス(−90%)が重なったとき、**乗算か加算か**。「弱点属性被ダメージ3%増加」は「弱点時の倍率を×1.03にする」でよいか、「倍率に+0.03する」か。「弱点属性増加被ダメージ-90%」は「弱点で増えた分(倍率−1)の90%を打ち消す」(倍率2→1.1)でよいか。

### 黄金の矢(8)
- **B1 入力と対象**: 対象タイプは Ground(マウス位置)だが効果は「指定の方向」へ撃つ。マウス**方向**でよいか。**長押しの判定**: 押した瞬間は発動せず、0.5秒未満で離すと扇状、0.5秒以上押すとビーム、でよいか(通常カードは押した瞬間に発動する現行の入力と異なる)。Lv1〜2でも長押しは待つのか、Lv3だけか。
- **B2 ダメージの意味**: 「矢1本につき50ダメージ」は固定値(Skillの式ではない)でよいか。Lv2の「スリップダメージ5秒間に計100」は、太くなった1本が当たった敵への継続ダメージか(重ねがけ/更新は?)。Lv3の「各矢のダメージが収束する」は、ビームのダメージ=11本分(550)か、他の値か。連続ヒットの間隔(1マスあたり3ヒット)とヒットストップの長さ・範囲(全体停止か敵だけか)。
- **B3 失敗と消費**: 「対象なし時: 対象外」「失敗条件: 攻撃が外れる」— 外れたとき**カードを消費するか**(Hermesの攻撃カードは「消費する」)。
- **B4 数値の不足**: 「高速」の速度、Lv3「間隔は10」の単位(度?)、矢は何かに当たると消えるか(貫通)、壁(「壁越え:いいえ」)で止まるか。

### エロスの矢(9)
- **B5 本数と時間**: 「1秒間に10本」は発射が1秒で終わるのか(合計10本)、押している間続くのか。Lv2「1方向につき7本」は発射時間が短くなるのか。方向転換は発射中にマウスで操作できるのか。
- **B6 追尾と対象**: 追尾する味方・敵の優先(最寄り? 味方優先?)。味方に当たった矢の回復は、主人公自身にも入るか。壁越え「はい」は矢が壁を通過するという意味か。Lv3の「まっすぐ飛ぶ矢がビームに変更」は、各方向の中央の1本か。

### 竪琴(10)
- **B7 音符**: 音符は4種(火力・速度・ヒール・病)と読むが、「3秒間に各音符が順番に3回」は合計3つか、4種×3回=12個か。押せる合計は3回で、Lv3の5回流れる場合の押せる回数は変わらないか。判定のタイミング幅(許容)。
- **B8 入力**: 「攻撃ボタン」は剣/銃の攻撃と同じボタンか。竪琴の演奏中は通常攻撃を止めるのか(押すと攻撃と音符が同時に反応する)。
- **B9 効果の合成**: 「同じ音符を選択すると効果が重なる」と「同じ音符を押すと効果時間が更新される」の両立(強さは重なり、時間は更新、でよいか)。重なりの上限。ヒール音符の「即時100+リジェネ3秒で100」。範囲の対象(味方=バフ/ヒール、敵=病)。Lv2の「すべて同じ音符」の判定と、クレンズの対象状態(どの状態を異常と呼ぶか)。失敗時の消費。

### 月桂冠(11)
- **B10 根の挙動**: 移動した軌跡に根が残り範囲が広がる(各区間が7秒で消える)でよいか。接触中の効果は「秒間50回復・被ダメージ−30%・弱点属性増加分−90%」。Lv3の壁は、**敵の遠距離攻撃が現行に存在しない**(§8)ため、何を防ぐのか。壁の強度・持続。

### ヒュアキントス(12)
- **B11 受付期間と花**: 受付期間(3秒/Lv3で5秒)の被ダメージ−90%は、最初の被弾だけか期間中ずっとか。花の持続時間・枚数。Lv2「パーティーにも付与」は各自が被弾したときに各自の花か。受付期間中に被弾しない=失敗のとき消費するか。Lv3の移動速度+80%の適用期間。

### ギガース殺し(13)
- **B12 チャージとダメージ**: 「オートチャージ」の時間。弱点状態(被ダメージ×2)と傷状態(+10%)の合成、病(+5%)との合成(A5)。「失敗条件: 範囲外」は射程∞と矛盾する(撃って外れたら失敗?)。

- **B13 効果の中身**: Lv1「次の敵の攻撃を予測する」= 何を表示するか(危険範囲の予告線?)。敵に予兆機能が現行に無い。Lv2「1秒間スロー」= 敵全体を何%減速するか(自分を除く)。Lv3「次の通常攻撃のダメージが2倍」= 主人公の次の武器ヒット(ストレングス・絶と同時のときの順序)。神託の強さは「強力」だが系統は「特殊」。
