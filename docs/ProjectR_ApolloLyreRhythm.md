# Apollo「竪琴」(apollo_lyre_rhythm) — Phase Apollo-A7

設計ID 10 / Apollo / 特殊 / 特殊 / 最大2枚 / 最大Lv3 / Cooldown 4秒 / その他(狙いなし = instant)/ 壁越え はい / 半径5マス。実装は `js/plugins/ProjectR_ApolloLyreRhythm.js`。数値は `data/ProjectR_CardBalance.json`(開発用エディタ F6)。旧「リラの支援/竪琴の鎮静」(`apollo_lyre_calm`)は置き換えず共存する。状態(病・火力)は共通の状態台帳 `ProjectR_ApolloStatus`。

## 1. ワークブックの記述(確定)
- Lv1: 発動後、プレイキャラクターの下に音符が一定間隔で流れる。(火力アップ10%・8秒 / スピードアップ10%・8秒 / 即時ヒール100 + リジェネ3秒間に100ヒール / 敵に病状態付与の音符)。3秒間に各音符が順番に3回流れてくる。攻撃ボタンをタイミングよく押すたびにその音符の効果を得られる。同じ音符を選択すると効果が重なる。音符は全部で3回押せる。音符を選択した瞬間に効果を得られる。同じ音符を押すと効果時間が更新される。病状態 = -10%攻撃力ダウン・被ダメージ5%増加・弱点属性被ダメージ3%増加。
- Lv2: すべて同じ音符を選ぶと、その効果の範囲が画面内すべてになり、味方の異常状態を解除するクレンズ効果も追加する。
- Lv3: 音符の流れる量が、3秒間に順番に5回に増加。
- 成功: 各音符をタイミングよく押す / 失敗: タイミングを外す。演出: 竪琴を持ったApolloが後ろに・音符を選ぶたびに演奏 / 指揮者のように手を振る / 選ぶたびに範囲が水面の波のように揺らぎ、音符の効果に対応した色の波紋 / 金色と各音符の色。

## 2. 実装(累積レベル)
使った瞬間に消費(instant)。3秒の演奏が始まり、音符(火力=赤・速度=青・ヒール=緑・病=紫)がプレイヤーの足元を右から左のライン(足元)へ流れる。音符の順は 火力 → 速度 → ヒール → 病 を `noteRounds` 周。最初の音符は0.6秒後にラインに届く。攻撃ボタン(Hendrixの攻撃入力 = 共通イベント1。実機のキーはJ)を押すと、その瞬間に最も近い音符(前後0.1秒以内)を選ぶ。最大3回(外れも1回に数える)。演奏中のこの入力は剣・銃へ流れない。

| Lv | 効果 | バランスの項目(既定) |
|---|---|---|
| 1 | 4種の音符x3周 = 12個(0.25秒おき)。選んだ瞬間の効果(半径5マス): 火力 攻撃力・魔力+10%x重なり(8秒)/ 速度 移動速度+10%x重なり(8秒。主人公)/ ヒール 即時100 + 3秒で100 / 病 敵に病(5秒。攻撃力x(1-0.1n)・被ダメージx(1+0.05n)・弱点x(1+0.03n)) | `noteRounds` 3 / `maxPresses` 3 / `hitWindowSeconds` 0.1 / `buffSeconds` 8 / `lyreAttackBonus` 0.1 / `lyreSpeedBonus` 0.1 / `lyreHealInstant` 100 / `lyreHealRegenTotal` 100 / `lyreHealRegenSeconds` 3 / `lyrePlagueSeconds` 5 / `lyrePlagueAttackDown` 0.1 / `lyrePlagueDamageTaken` 0.05 / `lyrePlagueWeakness` 0.03 |

| 3 | 5周 = 20個(0.15秒おき)。押せるのは3回のまま。判定の幅は音符の間隔の半分を超えないので前後4frameに狭まる | `noteRounds` 5 |

## 3. 仮の決め(ワークブックに無い部分。確定仕様として扱わない)
1. 「3秒間に各音符が順番に3回」は「4種類を順番に3周 = 12個」と読んだ(押せるのは3回)。Lv3は5周 = 20個。1周を何秒にするか・個数が違う読み(3個など)の可能性は、設計の追記待ち(監査文書 §10 B7)。
2. 「重なる」は加算(1 + 0.1 x n など)。同じ音符を押すと時間が更新される。重なりの上限は押せる回数なので自然に3。
3. タイミングを外した押下も1回に数える。回数を使い切ったあと・演奏が終わったあとの攻撃入力は通常どおり。演奏中は攻撃入力を音符に使う(銃・剣は動かない)。
4. 病の持続5秒・ヒールのリジェネは受けた味方に残る(範囲を出ても続く)。速度の音符は主人公のみ。
5. 「画面内すべて」は、ゲーム画面に見えているマップの範囲。3回とも同じ音符のとき、3回目の効果だけが画面全体になる。
6. クレンズの「異常状態」= 行動制限(restriction)を持つ・能力を下げる特徴を持つ・睡眠(32)・病(33)のState(死亡(1)・精神安定(34)は除く)。
7. 音は専用音が無く、RTPの Chime2 を音程違いで代用(火力100・速度112・ヒール126・病89)。音符の絵は自作(文字入りの丸)。波紋の絵は自作のDEV素材(`tools/gen_dev_a7_assets.cjs lyre`)。
