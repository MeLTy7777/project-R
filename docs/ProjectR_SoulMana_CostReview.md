## 前提(依頼どおり。ほかの規則は作っていません)
- マナは上限10、毎秒 +1 で回復。カードごとにマナコストがある。通常武器の攻撃間隔はマナと無関係で今のまま。
- 対象 = 今あるカード15枚(`data/ProjectR_CardBalance.json` のカード)。承認済みの9枚(SOUL専用の効果)と、従来の効果のままの6枚を含む。
- Lv効果は累積(Lv2はLv1+Lv2)。SOUL専用の9枚は承認済みのSOULでの効果(`ProjectR_SoulSkills.js` の説明と同じ)。残り6枚は元のカードの効果(`ProjectR_CardBalance.json`)。
- 現行クールダウンは `ProjectR_CardBalance.json` の値。絶だけSOULでは6秒(SOUL専用)。

## 推奨コストの付け方(根拠)
1. **基準 = 毎秒+1 で何秒分か。** コスト N のカードは、使うたびに N 秒ぶんの回復を消費する。現行のクールダウン(連続使用の間隔)を出発点にして、「強い単発・長い持続・大きな回復/停止」は高く、「小さな効果・連打向き」は低くした。
2. **上限10**: コスト6の神託は連続で1回(残り4)、コスト5のカード2枚で10を使い切る。コスト2〜3は短い間に数回、コスト4〜5は1〜2回に抑える設計。
3. **補助の優先度**: ダメージ・回復・停止・時間操作を比べ、時間を止める神託を最大の6、HPを大きく回復するものと停止系を5、標準の攻撃・補助を3〜4、小さな強化・連打向きを2とした。
4. **未確認の前提**: DEFENSE・PREPARE・神託の停止中にマナが回復するか(D7)、ATTACK開始時のマナ量(D7)、Lvでコストを変えるか(D8)は未決定。この案は「Lvでコストは変えない・ATTACK中だけ毎秒+1」を仮定しています。
