# Apollo「疫病の矢」(apollo_plague_rain) — Phase Apollo-A7

設計ID 15 / Apollo / 妨害 / 強力 / 最大4枚 / 最大Lv3 / Cooldown 5秒 / Direction / 壁越え はい / 有効範囲 半径4。実装は `js/plugins/ProjectR_ApolloPlagueRain.js`。旧「疫病攻撃(病の矢)」(`apollo_plague_attack`)は置き換えず共存する。数値は `data/ProjectR_CardBalance.json`(開発用エディタ F6)。病状態は共通の状態台帳 `ProjectR_ApolloStatus`。

## 1. ワークブックの記述(確定)
- Lv1: 病状態を付与する矢を発射し、着弾地点に病状態を付与するサークルを展開する。範囲は記載通り(半径4)。持続時間5秒。直撃100ダメージ(複数回Hit: いいえ)。
- Lv2: 着弾地点からネズミが召喚され、付近の敵を攻撃する。効果時間終了とともに消失。1秒に1回攻撃、ダメージ50。
- Lv3: 矢が分裂し、広範囲に広がる(ランダム)。
- 成功: 範囲内に敵がいた場合 / 失敗: 範囲外にいると失敗。演出: パープルゴールドの矢を降らす / 音「ファーン…ダスッ」/ 主人公は手を上げる。
- 病状態(竪琴の説明): -10%攻撃力ダウン・被ダメージ5%増加・弱点属性被ダメージ3%増加。

## 3. 命中と消費(予約→確定)
発動 → 矢が飛ぶ(カード未消費) → 着弾。いずれかの着弾で「直撃した、または半径内に敵がいた」最初の瞬間に、正規の経路で1回だけ消費する。すべての着弾で半径内に敵がいなければ失敗 = 非消費・Cooldownなし・サークルの絵も消す。飛行中の再発動は `plaguePending`。戦闘終了・マップ移動・ロード・死亡・対象の消滅で、矢・サークル・ネズミ・絵・状態をすべて片付ける。

## 4. 仮の決め(ワークブックに無い部分。確定仕様として扱わない)
1. Direction だが「着弾地点」があるため、矢はマウス位置へ飛ぶ(射程14マスで止める)。「半径4メートル」は4マス。壁は越える(矢は壁を判定しない)。
2. 病の持続は、サークルの中にいる間は更新され、出たあと3秒。サークルが消えても残りの3秒は残る。
3. Lv3: 分裂は4本・5マス以内にランダム(`Math.random`)。分裂した矢が敵を捉えた場合も「成功」。各矢が着弾してそれぞれ半径4のサークルを作る。ネズミはメインの着弾点だけ(最大10匹)。サークルの同時の絵は6つまで。
4. 直撃100・ネズミ50は固定ダメージ(無属性)で、被ダメージの倍率(病1.05・ギガース殺しの弱点x2など)の対象。病とギガース殺しの弱点は台帳が積(x2.1)にまとめる(監査文書 §10 A5 は未確定のまま)。
5. 着弾の瞬間に半径内に敵がいれば確定。サークルに後から入ってくる敵だけでは成功にならない(失敗の判定は着弾の時点)。
6. 音は専用音が無く、RTPの Bow3(発射)/ Blow5(着弾。連続は間引く)で代用。
