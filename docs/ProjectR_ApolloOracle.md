# Apollo「神託」(apollo_oracle) — Phase Apollo-A7

設計ID 14 / Apollo / 特殊 / 強力 / 最大3枚 / 最大Lv3 / Cooldown 3秒 / その他(狙いなし = instant)/ 壁越え いいえ。実装は `js/plugins/ProjectR_ApolloOracle.js`。数値は `data/ProjectR_CardBalance.json`(開発用エディタ F6)。

## 1. ワークブックの記述(確定)
- Lv1: 次の敵の攻撃を予測する。
- Lv2: 1秒間スローになる。(自分は含まない)
- Lv3: 次の通常攻撃のダメージが2倍になる。
- 演出: 後ろにApollo・指をはじく / 主人公は何もしない / 指をはじくと同時に光の粒子。Lv2以降は神の後ろに時計が出る(1秒で一周)/ 金 / 音「ニュータイプみたいな音」。

## 3. 仮の決め(ワークブックに無い部分。確定仕様として扱わない)
1. **「予測」の中身**(監査文書 §10 B13): 現行の敵AIには攻撃の予兆が無いため、実際に現れた敵の弾の進行方向を予告線で示す形にした。接触・近接など弾を使わない敵の攻撃は対象外。将来の敵AIが予兆を渡せるよう、`ProjectRApolloOracle.notifyAttack({x, y, degree, seconds})`(使ったあとの最初の1回だけ受け付ける)を用意してある。
2. スローの度合いはx0.5(Hermesの鈍足と同じ)・1秒。敵AIの攻撃間隔(クールダウン)は変わらない(移動と弾の速さだけ)。
3. 通常攻撃x2の有効期限は10秒(ワークブックに無い)。「通常攻撃」= 通常の剣/銃(絶・ストレングスと同じ武器ヒットの窓口)。ストレングス・絶との合成は、絶など「武器ヒット強化の枠」には積で重ね、ストレングス(攻撃力の差し替え)とは独立(どちらも別々に掛かる)。
4. 予測の待ち受けは5秒。弾が出なければ流れる(カードは使った時点で消費済み)。
5. 音は専用音が無く、RTPの Starlight(使用)/ Sound2(予告線が出たとき)で代用。時計・光の粒子は自作のDEV素材(`tools/gen_dev_a7_assets.cjs oracle`)。予告線はコードで描く(画像素材なし)。
