## 2. ストレングス

### 2.1 確定している仕様(ワークブック)
- Lv1: 次の物理攻撃の攻撃力を 10% 上昇。重ね掛け可(最大重複数なし)。重ね掛けは一度にすべて消費。
- Lv2: 上昇を 15% に(置換。重ね掛けは維持)。Lv3: 15% + 防御無視。
- 対象なし(対象外)・Cooldown 0.1秒・最大10枚・初回10枚。演出: Hermesは後ろ・足元の魔法陣・黄金の光・ガッツポーズ・黒いノイズで消える・Hermesのカットイン。音「輝く音」。

### 2.2 実装(「攻撃力」を上げる)
導入版Hendrixの武器ダメージ(`MaithlCalculateDamagePlayerWeapon`)は、武器のスキル式(攻撃スキル `a.atk * 4 - b.def * 2`、分散20%)を `a`=主人公Battler・`b`=対象Battler で評価します。
そこで `ProjectR_CardModifiers` のヒットフックが、その1回の `UpdateEventHp(-player weapon)` の間だけ、主人公Battlerのインスタンスに `param` を差し込み **攻撃力(param 2)に倍率を掛け**、Lv3では対象Battlerの **防御(param 3)を0** にします。呼び出しの後に必ず外します(`try/finally`)。基礎ATK・装備・Databaseは変更しません。
最終ダメージへの倍率ではないので、防御を引いた後の差が倍率以上に増えます(例: atk 31・def 20・分散最大 → 基準100、x1.3で145、x1.3+防御無視で 186 前後)。
防御無視は防御の項だけです。回避・無効・元素耐性・クリティカルの判定や、絶の最終ダメージ倍率には触れません。

### 2.3 重ね掛け(暫定)
- 回数 n、各回の上昇率 p(Lv1 0.10 / Lv2,Lv3 0.15。**各回はその時点のカードレベルの値を記録**)。
- 既定 `StackingMode = additive`: 攻撃力の倍率 = `1 + Σp`(Lv1を3回 = x1.30)。`multiplicative`: `Π(1+p)`(1.1³ = x1.331)。計算は `combine()` の1か所。
- **ワークブックに加算か乗算かの指定は無く、ユーザー承認済みの規則ではありません。**

### 2.4 対象になる攻撃の監査
| 攻撃 | 経路 | 扱い |
|---|---|---|
| 通常の剣 | `ProjectR_SwordSystem` → `UpdateEventHp(-player weapon)`(攻撃動作ID `sword:<serial>`) | **対象** |
| G17 | `ProjectR_GunSystem` → 同(`gun:<serial>`) | **対象** |
| 旧Hermes剣術・Apollo黄金の弓矢などのカード | `checkCollide` の時点でスキル式から計算済み(`<dmg:>`)。`UpdateEventHp` では攻撃力を差し替えられない | **対象外(未実装・要別の橋渡し)**。物理かどうかの判断も推測しない(スキルのhitTypeはすべて1=物理だが、計算時点が違う) |
| 薙ぎ払い・一閃の固定ダメージ | 攻撃力を使わない数値 | **対象外**(消費もしない) |
| 継続ダメージ・Ultimate | — | 対象外 |

### 2.5 消費の規則
- 蓄えは、次の通常武器攻撃が**実際にダメージを与えた**とき、全回数をまとめて1度だけ消費。外れ(回避・無効・0ダメージ)では消費しない。
- 1回の攻撃動作(同じ攻撃動作ID)が複数の敵に当たっても、全員に同じ強化がかかり、消費は1度。別の攻撃動作には残らない。
- 他のカードを使う・時間が経つ・メニューを開く、では消費しない。**期限はない**(戦闘終了・マップ移動・ロード・死亡で消える。保存しない)。
- 絶との併用: ストレングスで上げた武器ダメージに絶の倍率がかかる(両方1回ずつ消費)。片方だけでも、外れても、どちらも失われない。

## 3. 一閃

### 3.1 確定している仕様(ワークブック)
- 射程11マス・複数対象・壁越えなし・対象なしでも消費・Cooldown 7秒・最大3枚。
- ダメージ式「ヒット時防御無視で200ダメージ + スプリットダメージ」。Lv1 3秒間に50 / Lv2 3秒間に100 / Lv3 3秒間に100 + 敵の移動速度-50%を3秒間。
- 演出: Hermesが前に現れ11マスを居合斬り・白と黒の雷が経路に一瞬光る・主人公は腕を前に振り払う・黒いノイズで消える・風を切る音。

### 3.2 実装
- **1発動 = 1つの権威ある攻撃**。マウス方向を発動の瞬間に固定し、プレイヤー中心から一直線。経路は `firstBlockerBetween`(戦闘モード)で壁の手前まで(最大11マス)。経路の幅(`PathWidthTiles`、暫定1マス)に敵Eventの攻撃判定矩形(`eventPolygon`)が触れたら命中(SAT)。各敵に1発動1回。命中は**消費が確定した瞬間**に解決し、VFXの寿命とは無関係。ヒットボックス用のEventは作らない。
- 直接ダメージ: 固定200(防御を引かない・クリティカルなし)。手前の敵から順に与える。
- 分割ダメージ(暫定): 3秒かけて与える継続ダメージ。Lv1 合計50 / Lv2 合計100(置換)/ Lv3 合計100 + 移動速度x0.5を3秒。`SplitTicks`(既定3 = 1秒ごと)で等分し、端数は先の回へ(50 = 17,17,16 / 100 = 34,33,33)。**合計は必ず保存される**。各回は防御無視の固定ダメージ・クリティカルなし。再命中は置換(重ねない)。戦闘時間(カードのCooldownと同じ時計)で進む。対象が倒れた・消えた・戦闘終了・マップ移動・ロード・主人公の死亡で止まる。
- 移動速度低下: `ProjectR_CardModifiers.setCharacterSpeedFactor(event, "hermes_issen", 0.5)`。`Game_CharacterBase.distancePerFrame`(DotMoveの移動が使う)に敵Eventごとの係数の積を掛ける(WeakMap・保存しない)。他の係数は残り、期限で自分の係数だけ外れる。
- 主人公は動かない(テレポートなし)。Hermesが駆ける見た目は `ProjectR_GodSummonVisual.dash`(表示Eventの位置だけを動かす。判定・攻撃権限なし)。
