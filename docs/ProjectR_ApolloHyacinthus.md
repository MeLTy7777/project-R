# Apollo「ヒュアキントス」(apollo_hyacinthus) — Phase Apollo-A7

設計ID 12 / Apollo / 特殊 / 最大3枚 / 最大Lv3 / Cooldown 7秒 / Buff(狙いなし = instant)/ 壁越え いいえ / 範囲 半径2マス。実装は `js/plugins/ProjectR_ApolloHyacinthus.js`。数値は `data/ProjectR_CardBalance.json`(開発用エディタ F6)。軽減は共通の状態台帳 `ProjectR_ApolloStatus` を通して DamageModifiers へ。

## 1. ワークブックの記述(確定)
- Lv1: カード使用後、受付期間の3秒間中に使用キャラクターがダメージを食らうと、効果範囲(半径2マス)にヒヤシンスを咲かせる。味方が咲いたヒヤシンスに入ると秒間50ヒールする。受付期間中は被ダメージを90%軽減する。
- Lv2: カードの効果がパーティーメンバーにも付与される。
- Lv3: 受付期間が5秒になり、移動速度が80%上昇。
- 成功: 受付期間中にダメージを受ける / 失敗: 受付期間中にダメージを受けない。演出: ダメージを受けた後にApolloが召喚され、キャラクターを包む / 赤いヒヤシンスの花びらが散りながら効果範囲に広がる / 赤 / 音「ファーン」。

## 2. 実装(累積レベル)
| Lv | 効果 | バランスの項目(既定) |
|---|---|---|
| 1 | 使った瞬間に消費。受付期間3秒、使用者の被ダメージx0.1。被弾で半径2マスに花(6個)。花の中の味方は0.5秒ごとに25(秒間50)回復。花は8秒 | `acceptSeconds` 3 / `guardDamageTaken` 0.1 / `radiusTiles` 2 / `bloomSeconds` 8 / `bloomHealPerSecond` 50 / `bloomHealTickSeconds` 0.5 |
| 2 | 出撃中の仲間(PartyRoster)にも同じ受付期間 | `partyShare` 1 |
| 3 | 受付期間5秒(置換)。使用者の移動速度x1.8(受付期間の間) | `acceptSeconds` 5 / `speedBonus` 0.8 |

被弾の検出は使用者のHPの監視(どの経路のダメージでも)。軽減は ProjectR_ApolloStatus → DamageModifiers(HPを減らす呼び出し1回につき1回)で、重ねがけは台帳が1つにまとめる(DamageModifiersの既定は不変)。

## 3. 仮の決め(ワークブックに無い部分。確定仕様として扱わない)
1. **消費は使った瞬間**。受付期間に被弾しなくてもカードは消費済み(失敗 = 花が咲かないだけ)。「発動失敗条件」の扱いが未記載のため。
2. **花は参加者ごとに1つの受付期間につき1回**(最初の被弾で)。花の持続は8秒、花は6個(見た目)。
3. 「味方」= 主人公(使用者本人を含む)+ 出撃中の仲間。NPCは含まない。回復は満タンの者には何もしない。
4. **仲間の軽減はダウン判定の前に掛ける(Phase A9で変更)**: PartyCombat の被ダメージ窓口(`damageAlly`)は DamageModifiers に接続していない。以前は「受けた後の差し戻し」だったが、それでは致死の一撃(HP40への100など)が軽減されてもダウンした。今は `ProjectR_ApolloStatus` が `damageAlly` を包み(PartyCombat 本体は変えない)、`ally:<actorId>` の状態の被ダメージ倍率を、ダメージを渡す前に掛ける: 受けるダメージ = round(D x 0.1)。軽減後も致死ならダウンする。製品の仲間は現在0人なので、実際の戦闘では主人公だけが効果を受ける。
5. 受付期間中に同じカードを再使用すると、受付期間を更新する(軽減は重ならない・花は1回ぶん)。
6. 移動速度+80%は受付期間と同じ時間(使用者のみ。仲間は対象外)。
7. 音は専用音が無く、RTPの Heal4(花が咲く)/ Heal1(最初の回復)で代用。
